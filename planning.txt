2. TAHAPAN EKSEKUSI STANDAR (SOP DINAMIS PER WORKSPACE):
   Langkah 1: Setup koneksi database di koneksi/koneksi.php:
              - Tambahkan mysqli_report(MYSQLI_REPORT_OFF); di baris awal koneksi/koneksi.php untuk mencegah fatal exception mode default PHP 8.1+ terhadap MySQL 5.6.
              - Pastikan variabel koneksi ($database_ris, $database_pacsio, $database_mppsio) terbaca dinamis.
   Langkah 2: Pemindaian dinamis berkas & konfigurasi isolasi tools (rector.php & phpstan.neon):
              - Pindai struktur folder proyek RS aktif.
              - Daftarkan folder assets statis (css, js, image, fontawesome, maintenance_image, log) ke daftar skip.
              - Daftarkan modul pihak ketiga ke daftar skip (radiology/pdf, phpqrcode, ckeditor, vendor, phpmailer, contract, sign_src).
              - Siapkan rector.php dan phpstan.neon mandiri tanpa dependensi composer.
   Langkah 3: Perbaikan breaking changes PHP 8.3 pada kode aplikasi:
              - Null-Safety Query Relasi: amankan setiap pemanggilan query per-row ($res ? mysqli_fetch_assoc($res) : null) dan null coalescing ($row['field'] ?? '') pada tabel xray_take_envelope, xray_dokter_radiology, kop_surat, dan xray_expertise agar tidak melempar "Trying to access array offset on null".
              - Halaman Riwayat Expertise (workload-fill-detail-index.php): amankan query dokter radiologi terhadap username sesi login agar aman saat diakses akun radiographer atau refferal.
              - Patch Modul PDF (radiology/pdf/fpdf.php): hapus pemanggilan fungsi usang get_magic_quotes_runtime() di method _dochecks(), tambahkan atribut #[\AllowDynamicProperties] pada class FPDF & PDF_HTML, serta sediakan fallback default image untuk kop surat dan tanda tangan.
              - Isolasi Helper DataTables: lindungi fungsi get_all_data() dengan guard if (!function_exists('get_all_data')) pada semua script proses DataTables agar tidak fatal redeclare.
              - Helper Global: tambahkan fallback $server_name = $_SERVER['SERVER_NAME'] ?? 'localhost' di viewer-all.php.
              - Standarisasi Include: ubah seluruh include/require file helper ke path berbasis __DIR__ (require_once __DIR__ . '/../head.php').
              - Pembersihan Komentar HTML: bersihkan tag komentar <!-- ... --> yang berisi blok PHP <?php ... ?> dari variabel tak terdefinisi.
              - Direct Routing Session di index.php: hapus kode perantara menu.php dan langsung redirect ke modul sesuai session level pengguna.
   Langkah 4: Jalankan otomatisasi Rector & PHPStan:
              - Eksekusi refactoring aman: .\rector.bat process
              - Analisis statis: .\phpstan.bat analyse (Target: [OK] No errors di seluruh file aplikasi).
   Langkah 5: Audit Runtime Menyeluruh dengan Crawler (Simulasi Login 4 Role):
              - Jalankan script crawler pengujian untuk mensimulasikan login:
                1. Radiographer (akun staf radiografer)
                2. Radiology (akun dokter spesialis radiologi)
                3. Admin (akun administrator sistem)
                4. Refferal (akun dokter perujuk)
              - Pastikan seluruh endpoint DataTables, riwayat keahlian, viewer citra, dan cetak PDF mengembalikan HTTP 200 OK bebas dari Warning maupun Error.
